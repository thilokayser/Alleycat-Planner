# Alleycat Dispatch — Logo-Briefing

## Was ist das Projekt

Organizer-Tool für Alleycat-Rennen (Checkpoint-Straßenrennen für Fahrrad-Kuriere). Grassroots-Event-Software, kein Corporate-Produkt: wird von ehrenamtlichen Organisator:innen draußen im Feld benutzt, oft bei Wind und Wetter, auf Handys und Laptops.

## Wortmarke

**ALLEYCAT DISPATCH** — komplett in Großbuchstaben. Wirkt wie ein Funkspruch oder ein Depot-Zettel, nicht wie ein Tech-Markenname.

## Ästhetik-Richtung

Straßen-/Werkstatt-/Depot-Charakter statt glattem Tech-Look. Die im Code verwendeten Farbvariablen-Namen tragen die Metapher bereits in sich:

- Asphalt
- Papier (vergilbtes Karton-Papier)
- Tinte
- Warnweste (High-Vis)
- Stempel (Genehmigungsstempel)
- Stahl
- Kreide

## Farbpalette (Default/Dark-Theme)

| Rolle | Hex | Beschreibung |
|---|---|---|
| `asphalt` | `#17191a` | Fast Schwarz, Untergrundfarbe |
| `paper` | `#eee5cd` | Warmes, vergilbtes Papierbeige |
| `ink` | `#241f18` | Tinte, schwarzbraun |
| `hivis` | `#ff5f1f` | Warnorange — **Hauptakzent/Signalfarbe** |
| `stamp` | `#b23a2e` | Stempel-Rot — zweiter Akzent |
| `steel` | `#7c8388` | Stahlgrau |
| `chalk` | `#f3f1e8` | Kreideweiß |

Das Projekt hat weitere Themes (Light, Dark-Neutral, Dracula, High-Contrast) — die Rollen (`hivis`, `stamp`, `asphalt` etc.) bleiben über alle Themes gleich, nur die konkreten Werte wechseln. Für ein Logo sollte primär die Default-Palette oben als Referenz dienen.

## Motiv-Idee

Fahrrad + Checkpoint/Stempel-Element als Kernsymbol. Denkbar: Kartenpin, Zielflagge, Stempelabdruck — etwas, das die Checkpoint-Logik des Rennformats andeutet.

## Technische Anforderungen ans Logo

- Muss auf **sehr kleinen Flächen** funktionieren (Favicon, 16px)
- Muss **im Print** funktionieren, oft **s/w** (Startnummern/Bibs, Spokecards)
- Sollte auf **hellem und dunklem Hintergrund** lesbar sein (Light/Dark-Theme)
- Monochrom-Variante sinnvoll, da nicht überall Farbe verfügbar ist
